# 随机划分对照判读标准（2026-11-04 预注册，在跑 eval_random_split.py 之前写定）
#
# 目的（plan §12 A6 / §5 H7 / §20 表 3）：测量同场比赛信息共享对性能的高估幅度。
#
# 设计
#   - 随机协议：event 级 StratifiedKFold(5, shuffle, seed) 取一折作 test；其余样本再跑
#     一次 StratifiedKFold(5, 同 seed) 取第一折作 val。**去掉 group 键**——同一场点球大战
#     的罚球可以同时出现在 train/val/test。除分组外，其余与 match-disjoint 完全平行
#     （5 折、10 个 split seed 2027-2036、臂与 C 事先固定、train-only 标准化）。
#   - 对照协议：match-disjoint（build_folds.compute_folds），用同样的 seed 与臂重跑一遍。
#   - 置换：全局打乱 385 个标签 → **用同一份打乱标签同时重建两套 folds** → 重训全部臂。
#     两个协议必须都能建出合法划分（test/val 两类齐全），否则整体重抽。
#     因此 Δ 的零分布是配对的（同一次置换下两协议之差），不是两条独立零分布相减。
#   - 主统计量 pooled_rank（折内转秩后 pool），对 10 个 seed 取均值。
#   - 臂：只跑表 3 需要的四个关键臂 B1v2 / B2v2 / M1 / M3v2（本文件在跑脚本前修订：
#     原写"11 臂"，但多帧子集臂与表 3 无关，且子集在随机划分下语义不同，故收窄）。
#     每个协议的臂级零分布仍然分别给出，用于下面的"泄漏签名"判读。
#
# 判定
#   单臂"H7 成立"（随机划分高估该臂）：Δ = pooled_rank(random) − pooled_rank(matched)，要求
#     (a) 10 个 seed 中 ≥8 个 Δ > 0；(b) 配对置换 p_Δ < 0.05。
#   H7 整体成立：表 3 的四个关键臂中 ≥3 个单臂成立。
#   泄漏签名：某臂在随机协议下对自身零分布 p < 0.05、而在 match-disjoint 下不显著 →
#     读作"该臂的表观信号可由同场信息共享解释"；两协议下都显著 → 读作稳健效应
#     （不能写成泄漏）。任一协议下都不显著 → 该臂两种划分都无信号。
#   注意：随机协议的零分布均值不必等于 0.5，判读一律用各自协议自己的置换零分布，
#     不直接与 0.5 比较；两协议零分布均值之差也在报告中给出。
#
# 前置一致性断言
#   matched 协议的观测值须复现 results/reports/repeated_splits_20261104_141443.json 的逐臂
#   逐 seed 结果，否则中止（该断言在观测阶段、置换阶段之前执行，中止成本低）。
#   [2026-11-04 跑前勘误，不改变任何判定标准] 发现 11-04 报告存在一个复现缺陷：MLP 臂
#   （B2v2）建模型前未显式 seed，初始权重取自进程全局 RNG，同一 seed 重跑 pooled_rank 会
#   摆动 ±0.02~0.05；LR 臂（B1v2/M1/M3v2）逐位可复现。已在 eval_repeated_splits.py 补
#   torch.manual_seed，并在报告里加 determinism.mlp_init_seeded 标记（本次新跑的为 True）。
#   因此断言分两档：LR 臂 |Δ| < 1e-6（逐位），B2v2 |Δ| < 0.08（容差，覆盖实测摆动范围）。
#   本次 matched 协议的 B2v2 观测值与旧的"摆动抽样"不同属预期，不构成实现偏离。
#
# 预期（基于已有证据）：match-disjoint 下全部臂无信号（最好 B1v2 p=0.060）。
#   按 H7，随机协议预计抬高各臂 pooled_rank；若 Δ 仍不过配对置换检验，则写成
#   "在当前样本量下，同场信息共享对模型排序能力的影响测不出来"，并保留原始 Δ 数值。
