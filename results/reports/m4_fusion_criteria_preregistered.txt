## 0. 跑前诊断（描述性，不构成判定依据）

`scripts/diag_branch_logits.py`，10 split seed × 5 折（报告 `results/reports/
diag_branch_logits_20261109_120203.json`）：

- FER 支 logit（frozen LR 口径，C=0.01）test std ≈ 1.168，Context 支（B1v2，C=1）≈ 0.384，
  **尺度比中位 3.11×**；不标准化直接加权会让 w_fer 被系统性压低，故必须标准化；
- 标准化后两支 logit 的均值差中位仅 0.226（≈0.23 sd），即**标准化只修尺度、几乎不动偏置**，
  两支可比；
- 两支 test logit 相关 ≈ **−0.06**（独立，符合两支输入不同的预期）；
- FER 支 test AUROC 0.4664（复现主表 M1 0.467）；Context 支 0.5553（复现 B1v2 0.553）。

由此确定结构（见第 1 节）。**诊断本身不判定任何假设**，其数字不进论文。

## 1. 臂定义与对 plan §7.4 的偏离

**M4 定义**：两支先各自训好并冻结，融合层只拟合 3 个参数。

- **FER 支**：`enet_b0_8_best_vgaf`，解冻 `blocks[-1]`（717,232 参数）+ 线性头，判别式 lr
  （头 1e-3 / layer4 1e-4），BN 统计量冻结，AMP 关闭，输入为 `data/faces/<match>/k*.jpg`
  存盘 crop。**结构、超参、训练控制与 M2 完全一致**（`src/config/m2_finetune.yaml`），
  逐折从 pristine 拷贝并从零重训。输出 logit ℓ_f。
- **Context 支**：两个变体各跑一次（用户 2026-11-09 选定）：
  - 变体 **LR**：context v2 六维 + train-only 标准化 + LR（C=1.0），**与主表 B1v2 逐字段一致**；
    输出 logit ℓ_c = decision_function。
  - 变体 **MLP**：同一六维输入 + `ContextMLP(hidden=16, dropout=0.3)`，**与主表 B2v2 逐字段一致**；
    输出 logit ℓ_c（sigmoid 之前的量）。
- **融合层**：ℓ_f、ℓ_c 各自用**训练集**统计量标准化（硬约束 5），然后
  `p = σ(w_f · z_f + w_c · z_c + b)`，3 个参数（w_f, w_c, b）在**内层 val** 上拟合
  （3 参数容量下几乎无过拟合风险，且守硬约束 6：不用 test 选任何东西）。
- **命名**：`M4_lr`（context 支 = B1v2 口径）、`M4_mlp`（context 支 = B2v2 口径）、
  `M4_lr_tr` / `M4_mlp_tr`（描述性敏感性：融合层改在 train 上拟合）。

**对 plan §7.4 的偏离（须在论文中披露）**：§7.4 明写"两支投影到相近维度后拼接 + MLP 头"。
本臂改为"两支各输出 1 维 logit → 标准化 → 3 参数加权汇总"。理由：

1. **可归因性**：拼接方案里 1280 维 FER 会压倒 6 维 context（§7.4 自己也指出了这点），
   投影维度是新的自由超参，须 sweep；而现有证据（M3v2 − B1v2 = −0.086，10/10 seed 为负）
   表明融合整体无信号，再投入一个容量更大、需要 sweep 的融合器不可取。
2. **避免梯度塌缩**：若两支联合训练，w_f 的小值会等比缩小回传到 FER 支的梯度，
   "w_f ≈ 0"会变成优化路径的自证预言，而非数据结论。先训好再冻结可消除这个失效模式。
3. **可解释性**：标准化后 w/|w| 是**有量纲意义**的（每支 logit 每变动一个训练集标准差所
   贡献的 log-odds），两支可横向比较 —— 这正是 plan §13 第 6 条想读的量。
4. **成本**：支冻结后置换近乎免费（只需重训两支 LR/MLP），而拼接方案每次置换都要重训 backbone。

**局限（必须写进报告）**：本臂不再检验"两支在特征层能否发现交互项"（如 ℓ_f·ℓ_c），
只检验"两支在 logit 空间的加权线性组合"。§7.4 的交互性留作未实现项披露。

## 2. 超参（跑前固定，不做 sweep）

- FER 支：`src/config/m2_finetune.yaml` 原值（unfreeze_depth=1, lr 1e-3/1e-4, wd 1e-2,
  epochs 30, patience 5, batch 32, amp False）。**逐字复用 M2 已跑通的配置，不改任何值。**
- Context LR：C=1.0, max_iter=5000（主表 B1v2 原值）。
- Context MLP：使用 `src/config/context_v2.yaml` 的 `model.hidden=16 / dropout=0.3 /
  training.lr=1e-3 / wd=1e-2 / epochs=200 / patience=30`（主表 B2v2 原值）。
- 融合层：LR C=1.0, max_iter=5000（3 参数下 C 几乎不起作用，固定不 sweep）。
- 每个（split seed, 折, 置换）组合：**先 `torch.manual_seed(组合种子)` 再构造 FER 模型**
  （吸取 2026-11-04 init 未固定教训，见 memory/mlp-init-determinism-fix）。
- 标准化统计量：两支 logit 的均值/标准差**只由各折 train 估计**（硬约束 5），apply 到 val/test。

## 3. 协议

- 划分复用 `eval_repeated_splits.make_folds`（5 折 SGKF + 内层 val，match-disjoint，硬约束 4）。
- 观测值：10 个 split seed（2027–2036）× 5 折。**FER 支每个 (seed, 折) 只训一次**，
  两个 context 变体共用同一份 ℓ_f（保证 `M4_lr − M4_mlp` 的差只归因于 context 支）。
- 置换（降级口径，沿用 M2 口径与用户 2026-11-09 选定）：100 次 × 单 split seed 2027，
  打乱全部标签 → 同 seed 重建 folds → **全流程 refit**（FER 支逐次重训，context 支重训，
  融合层重新拟合），p_Δ = (1 + #{null_Δ ≥ obs_Δ}) / (1 + n_perm)。因单 seed，**无符号检验**，
  报告须标注降级口径，与主表其他臂（200 perm × 10 seed）不可直接比强度。
- 前置一致性守门（三个断言，任一失败即中止）：
  1. 本脚本的 B1v2 逐 seed 复现主表 181311 至 |Δ| < 1e-6；
  2. 本脚本的 B2v2 逐 seed 复现主表 181311 至 |Δ| < 1e-6；
  3. 本脚本的 M1（冻结 emb LR）逐 seed 复现主表 181311 至 |Δ| < 1e-6。
  这三条同时锁住 folds、标签、标准化口径与 MLP init 顺序。

## 4. 判读线

主指标 **pooled_rank**（折内转秩后 pool，全项目口径，plan §11）。

- **H8a（主判定，plan §0.5 指定线）**：`M4_lr − B1v2` 的配对置换 p_Δ < 0.05。
- **H8b（主判定，同基座对照）**：`M4_mlp − B2v2` 的配对置换 p_Δ < 0.05。
  与 H8a 并列的目的：把"context 基座选 B1v2 还是 B2v2"这一自由度与"FER 支有没有增量"
  分开——两个变体各自与自己的 context-only 基线配对，隔离基座选择的影响。
- **判定汇总**：H8 成立当且仅当 H8a 或 H8b 至少一条通过。若只有一条通过，
  报告必须写明是哪一条、另一条为何未过（并提示可能与 B2v2 自身弱于 B1v2 的 0.058 有关）。
- **预注册的次要比较（描述性，不判定，但必须全部报告）**：
  - `M4_lr − M4_mlp`（用户指定的两变体差异，隔离 context 支选择的影响）；
  - `M4_lr − M2` 与 `M4_mlp − M2`（隔离 FER 支固定的口径差）；
  - `M4_*_tr − M4_*`（融合层 fit-on-val vs fit-on-train 的敏感性，检查 val 拟合是否只是噪声）。
- **可解释性读数（描述性，严禁摁成因果）**：逐 seed、逐折记录 (w_f, w_c, b) 的取值、
  符号一致性、以及 |w_f| 与 |w_c| 的相对大小。**必须同时报告**：
  1. `w_f` 的绝对大小在支 logit 重标定下**不可识别**，只有 (w_f : w_c : b) 的等价类可读；
  2. 若两支都无信号，w 会随 val 的噪声漂移，**符号不稳定不能读成"FER 支为负贡献"**；
  3. 因此 `w_f ≈ 0` 的正确表述是"**未检出 FER 支的可测增量**"，**不是**"证明表情无信号"
     （检测下限见第 6 节）。
- 前置守门：任一断言失败即中止，不放宽判读线。

## 6. 已知限制（必须写进报告）

- **检测下限**：零分布 p95 ≈ 0.55–0.57；385 样本下 pooled_rank 低于约 0.55 的效应测不出来。
  阴性结论只能写成"未检出可测增量"，不能写成"证明无信号"。
- 置换零分布只在 seed 2027 这一套 folds 上成立；不能声称对其他 split seed 也成立。
- 无超参 sweep：固定超参下若融合层发育不良，记录现象，不放宽判读线。
- 融合层在内层 val（每折 6–7 场、约 40–74 例）上拟合，3 参数虽少，val 的噪声仍可能主导 w；
  `M4_*_tr` 敏感性对照即为检查这一点而设。若 fit-on-val 与 fit-on-train 的 pooled_rank
  差得很多，说明融合层的拟合位置主导了结果，须在报告中明确标注。
- 本臂不检验两支在特征层的交互项（见第 1 节最后一段），§7.4 的完整融合结构留作未实现项。
- 结果预期表述（若不显著）："385 样本下，融合在 logit 空间不产生可测的增量收益"，
  不写"表情与结果无关"，不写"融合无效"（融合器结构受限，超参未 sweep）。
